## Ukrainian Language for Big Walk

### English:
Adds Ukrainian language support to Big Walk. Fully human-made, no AI used, translated from the original English source. <br>
In the game, mod replaces the russian localization option, since I couldn’t make Ukrainian available as an additional option.

### Ukrainian:
Додає підтримку української мови до Big Walk. Переклад людиною (мною!! javy), без ШІ, на основі оригінального англійського тексту.<br>
У грі мод заміняє російську локалізацію, адже я не змогла зробити українську окремою опцією. Приємної гри!


## Automatic / Manual Installation

### Automatic:
Automatic installation via [<b>R2ModMan</b>](https://github.com/ebkr/r2modmanPlus/releases) is recommended.

### Manual:
1. Download [BepInEx IL2CPP](https://builds.bepinex.dev/projects/bepinex_be/785/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.785%2B6abdba4.zip).<br>
2. Extract the contents of that zip into your game directory (default: `C:\Program Files (x86)\Steam\steamapps\common\Big Walk`).<br>
3. Start the game and close it again to create BepInEx folders. <br>
4. Navigate to `...\Big Walk\BepInEx\plugins`, put `Ukrainian_BigWalk.dll` and `translations.json` into this folder. <br>
5. Run the game! If you've got any issues, please, contact me on Discord (<i>@javyfrogs</i>). <br>
